# Title fonts

All SIL Open Font License 1.1 (see OFL.txt), copied from this repo's
avian/frontend/fonts. The variable web fonts were pinned to one style with
fontTools so Pillow can use them:

| File | From | Settings |
|---|---|---|
| Fraunces-Display.ttf | Fraunces (stamp/fraunces-1.woff2) | opsz 144, wght 500 |
| Fraunces-DisplayItalic.ttf | Fraunces Italic (stamp/fraunces-0.woff2) | opsz 144, wght 400 |
| Newsreader-DisplayItalic.ttf | Newsreader Italic (stamp/newsreader-0.woff2) | opsz 72, wght 400 |
| InstrumentSerif-Regular.ttf / -Italic.ttf | Instrument Serif (stamp/instrument-*.woff2) | static |
| Caveat.ttf | Caveat (fonts/Caveat.ttf) | as shipped |

These are subsets (Latin letters, digits, common punctuation), which covers a
title like "Birds of the Hour".
